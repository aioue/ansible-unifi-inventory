# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/aioue/ansible-unifi-inventory/security/advisories/new). Include the affected collection and dependency versions, a sanitised reproduction, and the impact. Keep credentials, controller URLs, and private network details out of public issues.

Security fixes target the latest release. Maintainers review reports as availability permits; no response deadline is guaranteed. Ordinary bugs and feature requests belong in [GitHub issues](https://github.com/aioue/ansible-unifi-inventory/issues).
